# DIVE examples

This directory contains a worked example demonstrating the use of
DIVE with microbial community data and ecosystem functionality.

## Contents

### data/

Example input data used in the worked analysis.

- `tse_function.RData`: TreeSummarizedExperiment containing microbial
  abundance data and sampling dates.
- `Removal_Efficiency.xlsx`: ecosystem functionality measurements.

### analysis/

Scripts demonstrating how to run DIVE.

- `01_run_DIVE_BOD.R`: BOD removal analysis
- `02_run_DIVE_N.R`: nitrogen removal analysis
- `03_run_DIVE_P.R`: phosphorus removal analysis
- `04_extra_visualizations.R`: additional time-series visualizations

### results/

Example outputs generated by DIVE.

### visualizations/

Additional figures illustrating temporal patterns in alpha diversity
and ecosystem functionality.
